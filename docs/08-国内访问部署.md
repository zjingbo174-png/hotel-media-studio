# 国内网络访问部署（无代理、测试者无需账号）

> 问题：现在的线上地址是 GitHub Pages（`*.github.io`），**国内多数网络不打不开**，同事没有代理就用不了。
> 测试者本身**不需要 GitHub 账号**（公开网页谁都能打开），真正的障碍是域名在境内不可达。
>
> 解决办法：把同一份构建产物（`dist/` 文件夹）部署到**国内可访问**的静态托管。前端代码一行不用改，因为构建用的是相对路径 + Hash 路由。

## 1. 方案对比

| 方案 | 国内可访问 | 需要账号 | 测试者需要账号 | 备案 | 适合度 |
|---|---|---|---|---|---|
| **腾讯云 EdgeOne Pages**（推荐） | ✅ 腾讯 CDN | 腾讯云/微信扫码登录（免费） | ❌ 不需要 | 默认域名免备案 | ★★★★★ |
| Cloudflare Pages | ⚠️ 部分网络可访问 | 邮箱注册 | ❌ 不需要 | 免备案 | ★★★☆ |
| GitHub Pages（当前） | ❌ 多数网络不可达 | GitHub | ❌ 不需要 | 免备案 | ★☆（仅自己能翻墙时） |
| 阿里云 OSS / 腾讯云 COS 静态托管 | ✅ | 需实名 | ❌ | **默认域名会强制下载 HTML，必须备案域名** | ★ |
| 微信小程序 | ✅ 最稳 | 个人主体可注册 | ❌（微信内打开） | 免备案（平台审核） | 需重写，见 §5 |

## 2. 零账号临时验证：Netlify Drop（2 分钟，适合先看效果）

1. 打开发布好的压缩包解压（或直接用 `dist` 文件夹）；
2. 电脑浏览器打开 <https://app.netlify.com/drop>；
3. 把 `dist` 文件夹拖进去，几秒后得到一个 `https://xxxx.netlify.app` 网址；
4. 手机打开该网址验证。

优点：**完全不用注册**；缺点：匿名站点后续管理/更新不方便，且 Netlify 域名在部分国内网络可能不稳定。正式给同事用还是建议下面的 EdgeOne。

## 3. 推荐：EdgeOne Pages Drop（拖拽部署，约 10 分钟）
1. 在电脑上生成产物（已经有 `dist/` 可跳过）：
   ```powershell
   cd "D:\项目\计划表项目"
   npm run build
   ```
2. 打开 <https://pages.edgeone.ai/>，用**微信扫码或腾讯云账号**登录（免费，不需要 GitHub，不需要信用卡）。
3. 选择 **直接上传 / Pages Drop**，把项目里的 **`dist` 文件夹**整个拖进去（不是 `dist` 里面的文件，是文件夹本身）。
4. 等待几十秒，平台会给一个默认域名，形如 `https://xxxx.edgeone.app`。这就是你要发给同事的**固定网址**。
5. 手机浏览器打开该网址 → 添加到主屏幕，即可当 App 用（HTTPS，支持离线与安装）。

**验证清单**（部署完自己先看一遍）：
- 打开网址出现「每日计划」，不是空白或下载弹窗；
- 地址栏是 https，无混合内容警告；
- 手机安装后飞行模式能打开。

**后续更新**：本地改完 → `npm run build` → 回到 EdgeOne 项目重新上传 `dist` 覆盖即可（或绑定 Git 仓库自动部署，但需要先有 GitHub 账号，可选）。

> 说明：以上步骤依据 EdgeOne Pages 官方"拖放部署"能力整理；默认域名、免费额度与登录方式以控制台实际页面为准（截至 2026-10，官方提供免费静态托管与默认域名，无需备案）。参考：<https://pages.edgeone.ai/zh/resources/announcing-pages-drop-free-static-website-hosting>、<https://pages.edgeone.ai/zh/document/domain-overview>

## 4. 备选：Cloudflare Pages（有邮箱即可）

需要电脑已登录 Cloudflare（邮箱注册，免费）：

```powershell
npx wrangler pages deploy dist --project-name hotel-media-studio
```

会得到 `https://hotel-media-studio.pages.dev`。国内可达性因地区而异，先用手机 4G/酒店 WiFi 各试一次再发给同事。

## 5. 怎么把产物发给能部署的人

如果部署这一步由别人做，把整个 `dist` 文件夹压缩发过去即可，不需要源码、不需要 Node：

```powershell
Compress-Archive -Path dist\* -DestinationPath hotel-media-studio-v1.0.0.zip -Force
```

对方解压后把**文件夹内容**拖进 EdgeOne Pages 的拖放区（或按它的要求上传 zip）。

## 6. 关于微信小程序（你最初的首选）

技术上可以做，但有两个硬成本，建议等 URL 版本验证过再决定：

1. **不能跳转原视频/原笔记**：微信禁止小程序跳出到外部 App，只能复制链接/长按识别，核心的"一键跳转"会降级；而且个人主体小程序不支持 `web-view`，无法直接套现有 H5，需要原生重写（Taro/微信原生），3 个页面 + 数据层约 2–3 天。
2. **需要主体 + 审核**：个人可注册，但类目受限、每次更新要审核 1–3 天；数据共享还要接微信云开发（另一套后端）。

**如果最终目标是"同事打开就能用、不折腾账号"**：国内静态托管 + 网址（本方案）改造成本最低，微信里把链接发出去即可（微信内打开建议点右上角"在浏览器打开"，再添加到主屏幕）。

## 7. 测试者需要什么

- 一个能上网的手机；
- 你发过去的一个网址；
- 不需要 GitHub、不需要代理、不需要注册、不需要装应用商店的东西。

## 8. 数据说明（避免误会）

- 目前是**本地模式**：每个人的清单、收藏存在各自手机里，互不可见；
- 10 人共享内容库需要另部署协作后端（Cloudflare Worker 或腾讯云函数），见 [06-后端部署](06-后端部署.md)；部署后每台手机在「设置 → 团队协作」填服务地址 + 工作区码即可。
