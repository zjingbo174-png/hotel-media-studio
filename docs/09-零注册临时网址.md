## 1. 这个网址怎么来的

用 [BrewPage](https://brewpage.app/) 的公开 API 发布（免费、无需注册），把构建好的 `site/` 目录整站上传，得到一个独立子域名：

- 全程 HTTPS，支持"添加到主屏幕"；
- Service Worker 已通过验收：**断网后仍可打开、可打卡**；
- 已实测 8/8：首屏、manifest、图标、SW、离线、路由、无控制台错误。

## 2. 有效期与续期

- **有效期 30 天**（到 2026-11-26）。启动日志会打印过期时间。
- 过期后重新发布一次即可（约 3 秒）：
  ```powershell
  cd "D:\项目\计划表项目"
  node scripts/publish-site.mjs --build   # 重新构建到 site/
  node scripts/publish-brewpage.mjs       # 重新上传，打印新网址
  ```
- 每次发布得到**新网址**，旧网址到期失效。把新网址重新发给同事即可。
- `ownerToken` 存在 `.brewpage-owner.json`（已 gitignore），用于更新/删除，**不要提交或转发**。

## 3. 能做什么、不能做什么

| 能 | 不能 |
|---|---|
| 每日计划、打卡、增删任务、历史统计 | 长期固定网址（临时服务，30 天） |
| 选题灵感、热点二创、收藏内容库 | 10 人共享数据（需要另外部署协作后端） |
| 添加到主屏幕、断网打开 | 去广告/去掉右下角 BrewPage 小标识 |
| 手机/电脑浏览器直接用 | 作为正式长期产品域名 |

## 4. 如果这个网址在你网络打不开

说明 brewpage.app 在你的网络被拦，按顺序试：

1. **换网络**：4G/5G 流量打开一次，确认是网络问题还是域名问题；
2. **国内静态托管（最稳，需微信扫一次码）**：按 [08-国内访问部署](08-国内访问部署.md) 用 EdgeOne Pages 上传 `dist`，得到 `*.edgeone.app` 网址。**只有发布者需要扫码，打开网址的同事仍然什么都不用注册**；
3. **微信小程序**：完全不用网址、不用浏览器，但要重写（外链跳转会被降级为复制链接），见 08 第 6 节。
