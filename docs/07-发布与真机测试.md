## 1. 为什么是「网址 + PWA」而不是微信小程序

| | 当前方案（PWA 网址） | 微信小程序 |
|---|---|---|
| 打开 | 网址或桌面图标，全屏无地址栏 | 微信内搜索/扫码 |
| **跳转原视频** | 可以打开抖音/小红书 | **不行**，微信禁止跳出，只能复制链接 |
| 发布 | `git push` 自动上线，1 分钟 | 注册主体 + 提交审核，1–3 天/次 |
| 开源与自部署 | 代码在 GitHub，任何人可部署 | 依赖微信平台，无法自部署 |
| 通知 | 打开时提醒 | 订阅消息需后端，一次授权一条 |

结论：小程序会废掉"一键跳原视频"这个核心需求，所以用网址（PWA）。它是可以装到桌面的，用起来和 App 一样。

## 2. 手机怎么用（3 步）

1. 手机浏览器打开 <https://zjingbo174-png.github.io/hotel-media-studio/>
2. 安装到桌面：
   - **iPhone**：Safari → 分享 → **添加到主屏幕** → 名称「酒店创作台」→ 添加
   - **安卓**：Chrome → 右上角菜单 → **安装应用 / 添加到主屏幕**
3. 从桌面图标打开（全屏、无地址栏）。首次会出 3 步引导，可直接跳过。

> 装好后**断网也能打开并打卡**（数据存在手机本地），有网时正常使用。
> 想换手机/保留记录：设置 → 数据管理 → 导出备份，在新手机上导入。

## 4. 以后怎么更新网站

改完代码在项目目录执行：

```powershell
git add -A
git commit -m "feat: 你的改动"
git push
```

GitHub Actions 会自动跑测试、构建、发布，1–2 分钟后线上就是新版（`.github/workflows/deploy.yml`）。可在仓库 Actions 页看进度，失败会红叉。

> 本机 git 的全局代理配置（`http.proxy` / `http.https://github.com.proxy`）指向 127.0.0.1 的本地代理，代理没开时 push 会失败。临时绕过：
> `git -c 'http.proxy=' -c 'https.proxy=' -c 'http.https://github.com.proxy=' push`

## 5. 多人协作（10 人内，可选）

共享内容库、各自打卡需要一个小后端（前端网址是一套，数据服务是另一套）：

1. 按 [06-后端部署](06-后端部署.md) 部署 Cloudflare Worker + D1，得到 `https://hms-api.xxx.workers.dev`；
2. 每台手机：设置 → 团队协作 → 填服务地址 + 昵称 → 新建/加入工作区（6 位码，无密码）；
3. 验证：各自清单互不可见；收藏共享；刷新批次一致；设置页显示"在线 N 人"。

不部署后端也能用：默认本地模式，数据只在各自手机里。

## 7. 出问题怎么反馈

1. 设备与浏览器（如 iPhone 15 / Safari 18、小米 14 / Chrome）；
2. 卡在第几步、点击了什么、期望 vs 实际；
3. 截图（含地址栏）。

安卓可用 `chrome://inspect` 连电脑看控制台；iPhone 开「设置 → Safari → 高级 → Web 检查器」。
