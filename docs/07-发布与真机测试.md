**已知边界（不是 bug，属于当前版本设计）**

1. 内容为**演示数据**：选题/热点为自写虚构内容，"查看原内容"跳到平台搜索页，不是真实原视频。
2. **PWA 安装与离线需要 HTTPS**：局域网 `http://192.168.x.x` 只能测功能，浏览器不会注册 Service Worker，也无法"添加到主屏幕"。要完整测试请用 GitHub Pages 的 https 地址。
3. 提醒只在应用打开/后台运行时生效，关闭应用后无法推送。
4. 协作 token 存在本机 localStorage（详见 docs/04 剩余风险）。

## 2. 正式发布（GitHub Pages，推荐）

在项目目录执行（PowerShell）：

```powershell
cd "D:\项目\计划表项目"

# 1) 建远端仓库并推送（仓库名可改，公开/私有二选一）
gh repo create hotel-media-studio --public --source=. --remote=origin --push

# 2) 打开仓库 Pages 设置：Source 选 "GitHub Actions"
gh browse --settings
```

- 推送后 `.github/workflows/deploy.yml` 会自动跑测试、构建并发布。
- 在仓库 **Actions** 页看到 `Deploy to GitHub Pages` 变绿，即可访问：
  `https://<你的账号>.github.io/hotel-media-studio/`
- 首次部署约 1–2 分钟。

### 发布后自检（电脑上 3 步）

1. 打开上面的网址，页面加载出「每日计划」，地址栏没有报错。
2. F12 → Application → Manifest，能看到图标与名称（Chrome 可装）。
3. Application → Service Workers，状态为 activated。

## 3. 手机测试路径 A：局域网（现在就能做，5 分钟）

适合快速验证功能；**不能安装、不能离线**。

1. 电脑与手机连同一个 WiFi。
2. 电脑上启动（已为你启动，若关掉了就重跑）：
   ```powershell
   npm run build
   npx vite preview --host 0.0.0.0 --port 4173
   # 协作后端（可选，测多人时用）
   $env:HOST="0.0.0.0"; node server/dev.mjs
   ```
3. 手机浏览器打开 `http://<电脑局域网IP>:4173/`（本机示例：`http://10.111.103.65:4173/`，IP 以 `ipconfig` 为准）。
4. 看不到页面时：Windows 防火墙放行 Node（专用网络），或临时关闭防火墙测试。

## 4. 手机测试路径 B：正式 HTTPS（要测安装/离线就用这个）

1. 先完成第 2 节发布，得到 `https://xxx.github.io/hotel-media-studio/`。
2. 手机浏览器打开该地址。
3. **iPhone（Safari）**：分享 → 添加到主屏幕 → 名称「酒店创作台」→ 添加；从主屏幕图标打开（全屏、无地址栏）。
4. **安卓（Chrome）**：右上角菜单 → 安装应用 / 添加到主屏幕。
5. 安装后测试离线：打开一次 → 开飞行模式 → 从主屏幕重新打开 → 应仍能看到清单并打卡（数据存本机，恢复网络后不影响）。

## 6. 测多人协作（10 人内）

1. 手机打开应用 → 设置 → 团队协作 → 填服务地址 + 昵称 → 点"新建工作区"，记下 6 位工作区码。
2. 第二台手机/同事：填同一服务地址 + 工作区码 + 昵称 → 加入。
3. 验证：
   - 各自清单互不可见（A 加的任务 B 看不到）；
   - A 收藏的选题，B 在内容库能看到；
   - A 点刷新，B 切到选题页看到同一批次号；
   - 设置页显示"在线 N 人"。

> 服务地址在局域网测试时填 `http://<电脑IP>:8787`；正式用时填部署好的 Worker 地址（见 docs/06）。
> 注意：工作区创建限 5 次/小时/IP，加入限 10 次/分钟/IP，触发会提示限流。

## 7. 出问题怎么反馈

给我这三样，我就能定位：

1. 设备与浏览器（如 iPhone 15 / Safari 18、小米 14 / Chrome）；
2. 卡在第几步、点击了什么、期望是什么、实际是什么；
3. 截图（含地址栏或设置页版本号）。

安卓还可在 `chrome://inspect` 连电脑看控制台；iPhone 可开「设置 → Safari → 高级 → Web 检查器」。
