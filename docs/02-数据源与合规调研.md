# 抖音 / 小红书「当日爆款」数据源与合规调研

> 调研日期：2026-10-27。本文是 [01-需求分析](./01-需求分析.md) §3/§4.3/§8 的决策依据。
>
> 环境说明：本次调研的正文抓取（web_fetch）对所有域名均返回解析失败，仅能依据搜索引擎返回的标题与链接判断；标注「未核实」处为无法读取正文确认，勿当作接口事实使用。

## 1. 官方开放能力

- 抖音开放平台确有「热门视频榜单」「视频搜索」类**内容能力**，但属需单独申请的权限位，不是注册即用：[能力页](https://developer.open-douyin.com/m/capacity-center-page/capacity-detail/7180577040481910795)、[角色与权限](https://developer.open-douyin.com/docs/resource/zh-CN/developer/introduction/type-and-permission)。
- 开发者分个人/企业两类，内容、电商、生活服务类能力普遍要求**企业主体 + 行业资质 + 应用审核**；个人开发者主要拿到登录、分享等基础能力（具体清单未核实）：[入驻 FAQ](https://developer.open-douyin.com/docs/resource/zh-CN/developer/join/issues)、[平台入驻](https://open.douyin.com/platform/resource/docs/accession-guide/platform-accession/)。
- 「当日全网红榜 + 任意关键词」这种聚合查询，官方接口不提供组合形态；趋势/指数类数据主要走**巨量算数**（企业/服务商向）。
- 小红书开放平台公开文档以**电商（商品/订单/物流/售后）与本地生活**为主；「热门笔记榜 / 笔记搜索 / 笔记详情」**未见公开 API 文档**，品牌侧笔记数据在蒲公英、聚光、千帆后台，需品牌或机构身份，非开放接口（**未核实**是否存在定向合作接口）。

## 2. 第三方数据服务

- 新榜、蝉妈妈、飞瓜（抖音）、千瓜（小红书）、灰豚：均为 SaaS 形态，能力覆盖榜单、关键词搜索、达人/账号监测、笔记/视频明细导出。
- 是否提供 API：多为**商务签约制**（企业合同 + 按年/按调用量计费），无公开价目表，免费额度仅限试用或低配版；具体报价**未核实**。参考：[新榜](https://www.gopick.ai/tools/newrank)、[蝉妈妈](https://www.hxyou.cn/soft/3880.html)、[灰豚采集案例](https://learnku.com/articles/77111)。
- 另有大量「数据 API 代理」转售抖音指数/热点榜（如 [DataXAPI](https://dataxapi.com/zh/apis/douyin/index/)），价格低但**来源与授权不透明**，断供、字段失真风险高。

## 3. 开源 / 自建抓取

- [NanmiCoder/MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)：多平台关键词搜索 + 评论采集，靠浏览器自动化保存登录态绕过签名；仍活跃，但作者已将签名/代理能力做成付费服务，侧面说明风控成本：[分析](https://cloud.tencent.com.cn/developer/article/2700122)。
- [JoeanAmier/XHS-Downloader](https://github.com/JoeanAmier/XHS-Downloader)：小红书图文/视频下载，需 Cookie，活跃。
- [JoeanAmier/TikTokDownloader](https://github.com/JoeanAmier/TikTokDownloader)：抖音/TikTok 作品与评论采集，需 Cookie，活跃。
- 共性：**无官方授权、强依赖 Cookie 与签名、页面改版即失效**；历史上多个抖音爬虫因风控与法律压力停更或删库（未逐一核实）。

## 4. 合规与风险

- 抓取行为可能触及《网络安全法》第 27 条（不得非法侵入、干扰网络正常功能、窃取数据）、《数据安全法》（数据处理合规义务）、《个人信息保护法》（昵称、头像、评论属个人信息，需最小必要与告知同意）；情节严重可涉《刑法》285 条。法条全文见[国家法律法规数据库](https://flk.npc.gov.cn/)。
- 平台用户协议一般**明确禁止**爬取与批量导出：[抖音开放平台开发者服务协议](https://open.douyin.com/platform/resource/docs/operation-standard/agreement-protocol/)。违反协议通常导致封号、断接口，并可能被诉不正当竞争。
- robots 对登录后接口无强制力，但可作为「是否善意」的参考；笔记图文/视频受著作权保护，二创引用应控制在「适当引用 + 署名 + 不替代原作」，商用须授权。
- 两种情形边界：**本地个人学习**——风险相对低，但仍属违约，不可公开传播数据集；**公开部署**——向公众提供抓取内容，侵权与不正当竞争风险显著上升，必须走官方授权或持牌数据服务。

## 5. 结论：三条路线对比

| 路线 | 成本 | 稳定性 | 合规风险 | 推荐度 |
|---|---|---|---|---|
| (a) 纯演示数据（人工整理/Mock） | 极低（1–2 人日） | 高 | 近零 | ★★★★★ |
| (b) 半自动（粘贴链接 + 解析单条公开页） | 中（3–5 人日，需持续维护） | 中（改版即坏） | 中低（用户主动提供 + 合理使用） | ★★★★ |
| (c) 全自动（第三方 API / 自建爬虫） | 高（API 年费未核实；爬虫需长期对抗风控） | API 较高 / 自建低 | 最高 | ★★（仅在有预算 + 商务授权时） |

**结论**：首版采用 (a)，把「用户粘贴链接的半自动形态」(b) 作为 V2 优先方向；(c) 仅在预算与商务授权到位时考虑，且不自建爬虫。
